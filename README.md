### Pastimes 🛍️♻️

A modern marketplace for buying and selling quality second-hand fashion.

### 🌟 Why Pastimes?

Fashion doesn't have to be fast to be stylish. Pastimes connects buyers and sellers in a sustainable, community-driven marketplace where pre-loved clothing gets a second life.

What you can do with Pastimes

* 🛒 Discover unique second-hand fashion items

* ❤️ Save favorites to your wishlist

* 💬 Chat directly with buyers and sellers

* 📦 Manage orders and track purchase history

* 🏷️ List your own clothing items for sale

* 🛡️ Enjoy a secure, admin-moderated marketplace

### 🚀 Key Features

For Shoppers

* Browse a wide range of clothing items

* Search by name or brand

* View detailed product pages with images and descriptions

* Add items to your cart and checkout seamlessly

* Track your order history

For Sellers

* Upload and manage clothing listings

* Set prices, categories, and descriptions

* Communicate with interested buyers

* Apply for verified seller status

For Administrators

* Approve user and seller registrations

* Manage clothing listings

* Monitor orders and transactions

* Handle contact requests and support inquiries

### ⚡ Getting Started

Clone the repository and set up your local environment:

Then:

1. Create a MySQL database named storeclothing.

2. Configure your database credentials in DBConn.php.

3. Place the project in your web server's document root (e.g., htdocs for XAMPP).

4. Ensure the Uploads/ directory has write permissions.
